# M3 GUI Implementation Plan (pulled ahead of latency work at user request)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `vc-gui` — egui desktop app wrapping the live engine: start/stop, device pick, live pitch, window-param tweaking with Apply, VU meters, hop/miss/latency stats. Purpose: make backend tuning fast and visible.

**Architecture:** eframe/egui on the main thread. Audio side = existing vc-live logic refactored into a `livecore` module (vc-live becomes lib+bin): pw mainloop thread + worker thread, started/stopped by the GUI. Shared state via atomics (meters, stats, live pitch) + a command channel (start/stop/apply-params). Settings persisted to `~/.config/vc-native/settings.json`.

**Tech Stack:** `eframe` 0.3x, existing vc-live/vc-core. No web, no external assets.

## Global Constraints

- Build from `native/` cwd. Branch `native`. Commit per task, joke trailer.
- Live-tweak split: `pitch` = instant (atomic read per hop). `block/ctx_left/crossfade/lookahead/seed/input-device` = Apply button → stop+rebuild stream (sub-second mute acceptable).
- GUI must never block on audio; audio must never touch egui.
- Settings file versioned {v:1}; missing file = defaults.

---

### Task 1: refactor vc-live into lib + bin
`native/vc-live/src/lib.rs` exposing `livecore::{LiveConfig, LiveHandle, start(cfg) -> LiveHandle, LiveHandle::stop()}`, stats via `Arc<LiveStats>` (AtomicU64/AtomicU32 fields: in_rms_milli, out_rms_milli, hop_p50_us, hop_p95_us, misses, xruns, underruns, hops, internal_latency_ms) + `AtomicI32` live pitch. Worker + pw loop threads owned by handle; stop = flag + join + mic teardown. Bin main.rs = thin CLI over lib. Verify: `vc-live --tone` still works.

### Task 2: vc-gui skeleton
`native/vc-gui`: eframe window "vc-native", dark, 3 sections (status strip / controls / stats). Start/Stop button toggles livecore. Status: running state, capture node name, mic node name. Verify: starts+stops cleanly, mic appears/disappears.

### Task 3: controls
- Pitch slider -12..+12 semitones → AtomicI32, applied per hop (StreamEngine reads before convert; plumb setter).
- Input device ComboBox (pw-dump enumeration, refresh button), Apply.
- Window params: block/ctx/crossfade/lookahead sliders (320-sample steps, ms labels), seed box; Apply = restart stream w/ new cfg.
- Panic mute toggle: worker outputs silence while set (atomic).
- Monitor toggle: `pw-link vc_mic:capture_FL <default-sink>:playback_FL` (+FR) on, unlink off.

### Task 4: meters + stats
In/out VU bars (rms→dB, 100ms decay), hop p50/p95 vs budget bar, miss/xrun counters, est. mouth-to-ear readout (block/2 + hop_p50 + lookback + 40ms), repaint 30 Hz while running.

### Task 5: persistence + polish + ship
Save settings on change (serde_json), load at boot. Window title + about line. Commit, push, results note in m2-results addendum or m3 doc, memory update, user instructions.
